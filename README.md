# 📚 Banco de Dados II

## 📌 Descrição

Este repositório contém os materiais de aula, estudos e exercícios práticos desenvolvidos durante a disciplina de **Banco de Dados II**. O objetivo principal é registrar a evolução do aprendizado prático e teórico utilizando **SQL Server**, abordando desde a modelagem física até a construção de consultas complexas, manipulação de dados e conceitos avançados de bancos de dados relacionais.

## 🧠 Conteúdos Abordados

- **DDL (Data Definition Language):** `CREATE DATABASE`, `USE`, `CREATE TABLE`, `ALTER TABLE` (`ADD`/`DROP COLUMN`, `ADD`/`DROP CONSTRAINT`), `IDENTITY`.
- **DML (Data Manipulation Language):** `INSERT`, `UPDATE`, `DELETE`.
- **DQL (Data Query Language):** `SELECT` com `WHERE`, `ORDER BY`, `GROUP BY`, `HAVING`, `TOP`, `DISTINCT`.
- **Constraints & Integridade:** `PRIMARY KEY`, `FOREIGN KEY`, `CHECK`, `UNIQUE`, `NOT NULL`, `DEFAULT`.
- **Relacionamentos & Junções:** `INNER JOIN`, `LEFT JOIN`, Relacionamento Circular (Hierárquico / Auto-relacionamento).
- **Funções de Agregação:** `COUNT`, `SUM`, `AVG`, `MAX`, `MIN`, `ROUND`.
- **Funções de String:** `UPPER`, `LOWER`, `LEFT`, `RIGHT`, `SUBSTRING`, `ISNULL`.
- **Funções de Data:** `GETDATE`, `DATEDIFF`, `MONTH`, `YEAR`, `DATEFORMAT`.
- **Subqueries:** Subconsultas com `IN` e subselects na cláusula `WHERE`.
- **Objetos de Banco:** Criação e manipulação de Views (`CREATE VIEW`).
